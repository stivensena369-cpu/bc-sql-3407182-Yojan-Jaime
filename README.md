Base de Datos Escape Room — Semana 06

## Descripción

En esta semana se implementaron consultas utilizando funciones de agregación de SQL para generar reportes estadísticos sobre la base de datos del Escape Room.

## Funciones utilizadas

- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- GROUP BY
- HAVING

## Reportes implementados

- Total de salas registradas
- Capacidad total de jugadores
- Promedio de jugadores por sala
- Capacidad mínima y máxima
- Cantidad de salas por dificultad
- Filtrado de grupos mediante HAVING

## Tecnologías

- SQLite 3
- SQL

## Cómo ejecutar

Crear la base de datos

sqlite3 escape_room.db < Proyecto-week-6.sql

Abrir SQLite

sqlite3 escape_room.db

Ejecutar consultas

.read Proyecto-week-6.sql
